# 🌳 Spiritual BTree

A modern, interactive React application for visualizing and manipulating binary tree structures with a beautiful organizational chart interface.

## Overview

**Spiritual BTree** is an educational tool and visual sandbox for exploring binary tree data structures. It combines elegant visualizations with an intuitive UI, making it perfect for learning, teaching, and experimenting with tree algorithms.

### Key Features

- 🎨 **Interactive Visualization**: Display binary trees as hierarchical organizational charts
- ⚡ **Real-time Editing**: Edit node values directly from the visualization
- 🔄 **Tree Transformations**: Invert trees using both copying and in-place algorithms
- 📊 **Dynamic Tree Generation**: Create sample trees with configurable depth
- 🧪 **Type-Safe**: Built with TypeScript for robust development
- 📱 **Responsive Design**: Modern, clean UI that works across devices
